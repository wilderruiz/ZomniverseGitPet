# ZomniverseGitPet pet mockups

This design-review pack explores a more expressive desktop companion for ZomniverseGitPet. The six SVGs share a compact robot-cat guardian language: developer-tool neutrals, luminous state colors, simple silhouettes, and facial expressions designed to remain readable at small sizes.

## States

- `pet_idle_01.svg` — calm, upright everyday monitoring state.
- `pet_idle_02.svg` — alternate curled neutral pose with a Git branch motif.
- `pet_happy_01.svg` — cheerful healthy-repository state with a green check core.
- `pet_review_ready_01.svg` — attentive state for changes ready to review.
- `pet_warning_01.svg` — concerned, non-aggressive caution state.
- `pet_sleep_01.svg` — compact resting state for inactivity or paused monitoring.

## Preview

Open `mockups/pet/index.html` directly in a browser. The gallery has no build step, framework, network request, or external dependency.

**These mockups are not yet integrated into the live application.**
